# Демо-режим (пока не решены юридические вопросы)

## Что включено на проде
- 20 демо-продавцов (`*@demo.hobbyhub.ru`, общий пароль) и 40 карточек по Москве и Подмосковью
  (`backend/src/seed/demo-data.ts`, скрипт `npm run seed:demo`). У продавцов `users.isDemo = true`.
- Письма и push для демо-продавцов уходят на `DEMO_NOTIFY_EMAIL` (backend/.env) с темой
  «[Демо: Имя Фамилия] …».
- Оплаты нет: `PAYMENTS_DISABLED=true` (backend/.env) и `NEXT_PUBLIC_PAYMENTS_DISABLED=true`
  (frontend/.env.local). Подтверждение брони продавцом = бронь состоялась (статус `confirmed`),
  через 10 минут после окончания услуги она автоматически становится `completed` (для отзывов).

## Как вернуть всё обратно
1. Удалить обе переменные `*PAYMENTS_DISABLED` и `DEMO_NOTIFY_EMAIL`, задеплоить (frontend нужно пересобрать).
2. Убрать демо-данные: `cd /home/hobbyhub/app/backend && npm run seed:demo -- --remove`
   (удаляет демо-продавцов вместе с их услугами, расписанием и бронями; файлы фото в MinIO остаются).
3. Брони в статусе `confirmed`, созданные в демо-режиме, останутся как есть — проверить вручную.

## Известные ограничения
- Расписание у продавца одно на все его услуги; длительность услуги задаёт шаг слотов внутри окна.
